## 1. Какво е CSS?

**CSS** (Cascading Style Sheets) описва **как изглежда** страницата:
- как са подредени нещата на екрана;
- кое колко е голямо;
- какъв цвят са текстът, фонът и т.н.

| | Отговаря за | Аналогия |
|---|---|---|
| **HTML** | **Какво е** съдържанието | Стените и стаите |
| **CSS** | **Как изглежда** | Боята и мебелите |

### Три начина да добавим CSS

| Начин | Оценка |
|---|---|
| `style` атрибут | ❌ Избягвайте: смесва вида със съдържанието, не може да се преизползва |
| `<style>` в `<head>` | ⚠️ Става за малки примери |
| Външен файл с `<link>` | ✅ **Така се прави** |

**Примери:**

```html
<!-- 1. style атрибут: само за този един елемент -->
<p style="color: #b5373a;">Червен параграф.</p>

<!-- 2. <style> в <head>: важи за тази страница -->
<head>
    <style>
        p { color: #b5373a; }
    </style>
</head>

<!-- 3. Външен файл: важи за всяка страница, която го свърже -->
<head>
    <link rel="stylesheet" href="style.css">
</head>
```

**Защо външен файл:**
- **Един файл за всички страници.** Промяната е на едно място.
- **Кеширане.** Браузърът изтегля `style.css` веднъж и после го взима от кеша, вместо да го тегли наново за всяка страница.
- **Разделение на отговорностите:** HTML-ът остава чист.

## 2. Синтаксис

```
 селектор      декларация        декларация
    │      ┌──────┴─────┐    ┌───────┴───────┐
    h1    {  color: red;      font-size: 32px;  }
             └─┬─┘ └┬┘        └───┬───┘ └─┬─┘
            свойство стойност   свойство  стойност
```

- **Селекторът** казва **кои** елементи да се стилизират.
- **Декларацията** е двойка `свойство: стойност;`.
- Браузърът прилага стила на **всички** елементи, които селекторът е избрал.
- **`!important`** след стойността (`color: red !important;`) кара декларацията да бие всички останали правила, но не е добра практика: заобикаля нормалните правила за кой стил печели, и после единственият начин да я промените е с още `!important`.

**Примери:**

```css
/* Това е коментар в CSS */
h1 {
    color: #1f4e79;  /* цвят на текста */
    font-size: 2rem;  /* размер на шрифта: 2rem = 32px */
}

/* Няколко декларации за един селектор */
p {
    color: #222;  /* цвят на текста */
    line-height: 1.6;  /* височина на реда: 1.6 × размера на шрифта */
    margin-bottom: 1rem;  /* външно отстояние отдолу: 1rem = 16px */
}

/* Един стил за няколко селектора наведнъж */
h2, h3 {
    color: #1f4e79;  /* цвят на текста */
}
```

> ⚠️ **Размерите винаги са с мерна единица.** `font-size: 10` е **невалидно** и браузърът ще го игнорира. Правилно: `font-size: 10px`. Изключения: `0` (може без единица) и `line-height` (може число: `1.5`).

## 3. Селектори

### Основни

| Селектор | Избира |
|---|---|
| `*` | Всички елементи |
| `p` | Всички `<p>` |
| `.price` | Елементи с `class="price"` |
| `#menu` | Елемента с `id="menu"` |
| `nav a` | `<a>`, които са **някъде вътре** в `<nav>` |
| `h1, h2` | **И** `<h1>`, **и** `<h2>` |

**Примери:**

```html
<nav class="menu">
    <ul>
        <li><a href="#home">Начало</a></li>
        <li><a href="#courses" id="current">Курсове</a></li>
        <li><a href="https://www.fmi.uni-sofia.bg/">ФМИ</a></li>
    </ul>
</nav>
<p class="price">12,50 лв.</p>
```

```css
* { box-sizing: border-box; }          /* всички елементи: width включва padding и border */
p { line-height: 1.6; }                /* всички <p>: височина на реда 1.6 × шрифта */
.price { color: #2e7d32; }             /* class="price": зелен текст */
#current { font-weight: bold; }        /* id="current": удебелен шрифт */
.menu a { color: #1f4e79; }            /* <a> вътре в .menu: тъмносин текст */
h1, h2 { font-family: Georgia, serif; } /* и двете: шрифт Georgia, иначе какъвто и да е serif */
```

> 💡 `*` се ползва най-често за `* { box-sizing: border-box; }`: стандартен първи ред в почти всеки CSS файл днес (вижте раздел 11).

### Комбиниране: `tag#id.class`

```css
a.external      { }  /* <a> с клас external */
p.note.warning  { }  /* <p> с двата класа note и warning */
li#current      { }  /* <li> с id="current" */
```

### Още селектори

| Селектор | Избира |
|---|---|
| `ul > li` | `<li>`, които са **директни** деца на `<ul>` |
| `h2 + p` | `<p>`, който е **точно след** `<h2>` |
| `li:first-child` | `<li>`, който е **първото** дете на родителя си |
| `tr:nth-child(2n)` | Всеки **втори** ред (за редуващи се цветове) |
| `a:hover` | Линк, **докато мишката е върху него** |
| `input:focus` | Поле, **в което е курсорът** |
| `button:focus-visible` | Бутон, до който сте стигнали с **клавиатурата** |
| `input[type="email"]` | Полета с **атрибут** `type="email"` |
| `a[href^="https"]` | Линкове, чийто `href` **започва** с `https` |
| `input::placeholder` | Текстът на `placeholder` вътре в полето |

**Примери:**

```css
/* Първият параграф след всяко h2 е малко по-голям: въведение */
h2 + p { font-size: 1.125rem; }  /* размер на шрифта: 1.125rem = 18px */

/* Първата точка от списъка е удебелена */
li:first-child { font-weight: bold; }  /* удебелен шрифт */

/* Редуващи се цветове в таблица */
tr:nth-child(2n) { background-color: #f2f5f9; }  /* цвят на фона */

/* Подчертаване на линк само при посочване */
a { text-decoration: none; }  /* без подчертаване */
a:hover { text-decoration: underline; }  /* подчертан */

/* Видима рамка при фокус: и с мишка, и с клавиатура */
input:focus { outline: 2px solid #1f4e79; }  /* контур около елемента (не заема място, за разлика от border) */
button:focus-visible { outline: 3px solid #f2a900; }  /* контур около елемента (не заема място, за разлика от border) */

/* Стрелка след всеки външен линк */
a[href^="https"]::after { content: " ↗"; }  /* текст, който CSS добавя: " ↗" */

/* По-блед текст в placeholder-а */
input::placeholder { color: #888; }  /* цвят на текста */
```

> ⚠️ `:hover` работи на **всички** елементи, но **на телефон няма мишка**, затова `:hover` не е достатъчен. Винаги добавяйте и `:focus-visible`, за да виждат и хората с клавиатура къде са.

> 🎮 **Упражнение:** играта **CSS Diner** (https://flukeout.github.io) учи селекторите за 20 минути.

## 4. Каскада и специфичност: кой стил печели?

Какво става, ако два стила казват различни неща за един и същ елемент?

```css
p { color: blue; }  /* цвят на текста */
.note { color: green; }  /* цвят на текста */
```

```html
<p class="note">Какъв цвят съм?</p>
```

<details>
<summary>Отговор</summary>

**Зелен.** Селекторът с клас е **по-специфичен** от селектора с таг.

</details>

### Специфичност: как се брои

Специфичността се брои като три числа: **(id, клас, таг)**. Сравнява се отляво надясно: едно `id` бие произволен брой класове.

| Селектор | id | клас | таг | Специфичност |
|---|---|---|---|---|
| `a` | 0 | 0 | 1 | **0, 0, 1** |
| `p a` | 0 | 0 | 2 | **0, 0, 2** |
| `.whatever` | 0 | 1 | 0 | **0, 1, 0** |
| `a.whatever` | 0 | 1 | 1 | **0, 1, 1** |
| `.whatever .whatever` | 0 | 2 | 0 | **0, 2, 0** |
| `#whatever` | 1 | 0 | 0 | **1, 0, 0** |
| `.whatever .whatever #whatever` | 1 | 2 | 0 | **1, 2, 0** |
| `#whatever #whatever` | 2 | 0 | 0 | **2, 0, 0** |

> 💡 Популярна аналогия от статията на Анди Кларк *CSS: Specificity Wars*: тагът е щурмовак, класът е Дарт Вейдър, а id-то е Императорът. Колкото и щурмоваци да има, Вейдър ги бие, а Императорът бие всички Вейдъри.

**Какво още брои:**
- `:hover`, `:first-child`, `[type="email"]` се броят като **клас**.
- `::placeholder` се брои като **таг**.
- `*` не брои нищо.

### Правилата на каскадата

1. **По-високата специфичност печели.**
2. **При равна специфичност печели последното правило** във файла.
3. **`style` атрибутът** бие всички селектори.
4. **`!important`** бие всичко. ⚠️ Избягвайте го: щом го ползвате веднъж, после ви трябва навсякъде.

**Примери:**

```css
/* Правило 1: id (1,0,0) бие клас (0,1,0) */
#special { color: purple; }  /* цвят на текста */
.note    { color: green; }  /* цвят на текста */
/* <p id="special" class="note"> е лилав */

/* Правило 2: еднаква специфичност → печели последното */
.badge { background-color: #b5373a; }  /* цвят на фона */
.badge { background-color: #2e7d32; }  /* цвят на фона */
/* .badge е зелен */

/* Правило 4: !important бие дори id (но не го правете) */
.forced { color: orange !important; }  /* цвят на текста (!important) */
/* <p id="special" class="forced"> е оранжев */
```

### Наследяване

Някои свойства се **наследяват** от родителя, други не.

| Наследяват се | Не се наследяват |
|---|---|
| `color`, `font-family`, `font-size`, `font-weight`, `line-height`, `text-align` | `margin`, `padding`, `border`, `width`, `height`, `background` |

**Пример:**

```css
.parent {
    color: #b5373a;  /* цвят на текста (наследява се) */
    font-style: italic;  /* наклонен шрифт (наследява се) */
    border: 2px solid #b5373a;  /* рамка: дебелина, вид, цвят (НЕ се наследява) */
}
```

```html
<div class="parent">
    <p>Червен и наклонен, като родителя, но без рамка.</p>
</div>
```

> 💡 Браузърът има **собствени стилове по подразбиране** (*user agent stylesheet*): големи `<h1>`, сини подчертани линкове, `margin` на `<body>`. Вашият CSS ги **замества** по същите правила. Вижте ги в DevTools: в **Styles** са отбелязани с „user agent stylesheet".

## 6. Цветове

| Начин | Пример | Бележка |
|---|---|---|
| Име | `red`, `white`, `tomato`, `transparent` | Около 140 имена |
| HEX | `#ff0000`, кратко `#f00` | Червено, зелено, синьо в шестнадесетичен запис |
| RGB | `rgb(255, 0, 0)` | Всеки канал от 0 до 255 |
| HSL | `hsl(0, 100%, 50%)` | **Тон** (ъгъл в цветовия кръг 0–360°), **наситеност** и **светлина** в % |
| С прозрачност | `rgba(255, 0, 0, 0.3)`, `hsla(0, 100%, 50%, 0.3)` | Последното число е **алфа**: 0 = прозрачно, 1 = плътно |

**Съвременен запис** (работи във всички браузъри):

```css
color: rgb(255 0 0 / 30%);  /* цвят на текста */
color: hsl(0 100% 50% / 0.3);  /* цвят на текста */
```

**Примери: един и същ цвят по пет начина**

```css
.c-name  { background-color: tomato; }  /* цвят на фона */
.c-hex   { background-color: #ff6347; }  /* цвят на фона */
.c-rgb   { background-color: rgb(255 99 71); }  /* цвят на фона */
.c-hsl   { background-color: hsl(9 100% 64%); }  /* цвят на фона */
.c-alpha { background-color: rgb(255 99 71 / 40%); } /* цвят на фона, 40% непрозрачен */
```

**Пример: по-тъмен вариант с HSL**

```css
.btn       { background-color: hsl(210 60% 40%); }  /* цвят на фона */
.btn:hover { background-color: hsl(210 60% 30%); } /* цвят на фона: същият тон, по-тъмен */
```

> 💡 **HSL е най-удобен за хора:** за по-тъмен вариант на същия цвят просто намалете последното число.
>
> ♿ **Контраст:** текстът трябва да се чете. Изискването за достъпност е съотношение поне **4.5 : 1** за обикновен текст. DevTools го показва в палитрата. Например бял текст на светлозелено (`#9bc010`) има контраст около **2 : 1** и **не минава**.

## 7. Мерни единици

Ключът е един въпрос: **спрямо какво се мери?** `px` е фиксиран размер, а всички останали единици са **част от нещо друго**.

За примерите приемаме:
- шрифтът на страницата (`<html>`) е **16px**, по подразбиране;
- кутията-родител е широка **800px**;
- прозорецът на браузъра е **1200 × 800px**.

### `px`: фиксиран размер

Като линийка: `10px` винаги е 10px, където и да е.

```css
border: 1px solid #ccc;   /* рамка, дебела точно 1px */
```

### `rem`: спрямо шрифта на цялата страница

`1rem` = шрифтът на `<html>` = **16px**. Винаги, навсякъде на страницата.

| Пишете | Получавате |
|---|---|
| `1rem` | 16px |
| `2rem` | 32px |
| `0.5rem` | 8px |
| `1.5rem` | 24px |

```css
h1 { font-size: 2rem; }   /* 2 × 16 = 32px */
```

> ♿ **Защо е полезно:** ако потребителят увеличи шрифта в настройките на браузъра, например на 20px, всичко с `rem` пораства заедно с него: `2rem` става 40px. С `px` нищо не се променя.

### `em`: спрямо шрифта точно на това място

`1em` = размерът на шрифта на **самия елемент**.

```css
.card {
    font-size: 20px;   /* размер на шрифта на картата */
    padding: 1em;      /* 1 × 20 = 20px */
}
```

Ако шрифтът на картата стане 30px, отстоянието автоматично става 30px. Отстоянието расте заедно с текста.

> ⚠️ **Капанът:** когато `em` се ползва за самия `font-size`, мерилото е шрифтът на **родителя**. При вложени елементи размерът се натрупва:
>
> ```css
> li { font-size: 1.2em; }   /* 1.2 × шрифта на родителя */
> ```
>
> | Ниво | Сметка | Резултат |
> |---|---|---|
> | Списък | 1.2 × 16px | 19.2px |
> | Списък в списъка | 1.2 × 19.2px | 23px |
> | Още едно ниво | 1.2 × 23px | 27.6px |
>
> С `1.2rem` и трите нива са **19.2px**, защото `rem` винаги гледа само `<html>`.

### `%`: спрямо кутията, в която е елементът

```css
.half { width: 50%; }   /* родителят е 800px → 400px */
```

Ако родителят се свие до 600px, елементът автоматично става 300px.

> ⚠️ `height: 50%` работи само ако родителят има **зададена** височина. Иначе браузърът няма от какво да вземе 50%.

### `vw` и `vh`: спрямо прозореца на браузъра

`1vw` е 1% от **ширината** на прозореца, а `1vh` е 1% от **височината** му.

| Пишете | Получавате (прозорец 1200 × 800) |
|---|---|
| `100vw` | 1200px: цялата ширина |
| `50vw` | 600px |
| `100vh` | 800px: цялата височина |
| `40vh` | 320px |

```css
.hero { min-height: 100vh; }   /* поне колкото целия екран */
```

### `pt`: точка, като в Word

За печат. На екран не се ползва.

### Обобщение: кое кога

| Искам… | Използвам |
|---|---|
| Размер на шрифта | `rem` |
| Отстояния (padding, margin) | `rem`, или `em`, ако трябва да растат с текста |
| Тънка рамка | `px` |
| Ширина спрямо родителя | `%` |
| Нещо колкото екрана | `vw` / `vh` |

### 🤔 Бърза проверка

Шрифтът на страницата е 16px.

1. `3rem` = ?
2. Елемент с `font-size: 10px` и `padding: 2em`. Колко е отстоянието?
3. Родител 500px, дете с `width: 20%`. Колко е широко детето?

<details>
<summary>Отговори</summary>

1. 3 × 16 = **48px**
2. 2 × 10 = **20px** (`em` е спрямо шрифта на самия елемент)
3. 20% от 500 = **100px**

</details>

## 8. Текст и шрифтове

### Текст

| Свойство | Стойности |
|---|---|
| `color` | Цвят на текста |
| `text-align` | `left`, `right`, `center`, `justify` |
| `text-decoration` | `none`, `underline`, `overline`, `line-through` |
| `text-transform` | `none`, `uppercase`, `lowercase`, `capitalize` |
| `line-height` | Височина на реда: `1.5` (число, без единица, е най-добре) |
| `letter-spacing` | Разстояние между буквите |

**Примери:**

```css
.title-upper {
    text-transform: uppercase;  /* главни букви само на екрана: в HTML пише „Регистрация" */
    letter-spacing: 0.1em;  /* разстояние между буквите */
    text-align: center;  /* текст в центъра */
}
.old-price { text-decoration: line-through; color: #888; }  /* зачеркнат; цвят на текста */
.justified { text-align: justify; }  /* двустранно подравняване */
```

> 💡 `text-transform: uppercase` е по-добре от текст, написан С ГЛАВНИ БУКВИ в HTML-а: съдържанието остава нормално, а видът е работа на CSS.

### Шрифтове

| Свойство | Стойности |
|---|---|
| `font-family` | Списък шрифтове; използва се **първият наличен** |
| `font-size` | Размер: `1rem`, `18px` |
| `font-weight` | `normal`, `bold` или число от `100` до `900` (`400` = normal, `700` = bold) |
| `font-style` | `normal`, `italic` |

- Имена с интервал се пишат в **кавички**.
- **Винаги завършвайте с общо семейство:** `serif` (със засечки), `sans-serif` (без засечки) или `monospace` (за код). Ако никой от шрифтовете го няма, браузърът ползва поне правилния тип.

**Примери:**

```css
body {
    font-family: "Segoe UI", Roboto, Arial, sans-serif;  /* шрифт: използва се първият наличен от списъка */
    font-size: 1rem;  /* размер на шрифта: 1rem = 16px */
    line-height: 1.6;  /* височина на реда: 1.6 × размера на шрифта */
}
code {
    font-family: Consolas, "Courier New", monospace;  /* шрифт: използва се първият наличен от списъка */
}
.light { font-weight: 300; }  /* тънък шрифт (300) */
.heavy { font-weight: 800; }  /* много дебел шрифт (800) */
```

**Кратък запис `font`:**

```css
/* font: стил тегло размер/височина-на-реда семейство; */
.quote { font: italic bold 1.125rem/1.5 Georgia, serif; }  /* кратък запис: стил тегло размер/височина-на-реда семейство */
.plain { font: 1rem Verdana, sans-serif; }  /* кратък запис: задължителни са само размер и семейство */
```

## 9. Фон

| Свойство | Стойности |
|---|---|
| `background-color` | Цвят на фона |
| `background-image` | `url("snimka.jpg")` или градиент |
| `background-repeat` | `repeat`, `repeat-x`, `repeat-y`, `no-repeat` |
| `background-position` | `top left`, `center`, `50% 50%`, `10px 20px` |
| `background-size` | `cover` (покрива целия елемент), `contain` (цялата картинка се вижда), `100px auto` |
| `background-attachment` | `scroll`, `fixed` (картинката не се движи при скролиране) |

**Примери:**

```css
/* Само цвят */
.bg-color { background-color: #e8eef5; }  /* цвят на фона */

/* Градиентът също е „картинка": генерира се от CSS, без файл */
.bg-gradient { background-image: linear-gradient(to right, #1f4e79, #6a9bd1); }  /* фонова картинка: преливане от един цвят в друг */

/* Повтаряща се шарка: малка точка, повторена през 20px */
.bg-dots {
    background-image: radial-gradient(circle, #9fb3c8 2px, transparent 2px);  /* фонова картинка: кръгъл градиент (малка точка) */
    background-size: 20px 20px;  /* размер на фоновата картинка: 20px 20px */
    background-repeat: repeat;  /* фоновата картинка се повтаря */
}

/* Кратък запис: цвят, снимка, повторение, позиция / размер */
.bg-photo {
    background: #1f4e79 url("snimka.jpg") no-repeat center / cover;  /* кратък запис: цвят, картинка, повторение, позиция / размер */
}
```

> ♿ Ако текст стои върху снимка, задайте и `background-color`. Ако снимката не се зареди, текстът пак ще се чете. (В примерния файл `snimka.jpg` нарочно липсва: виждате резервния цвят.)

## 10. Display: как се държи елементът

| Стойност | Как се държи | Примери по подразбиране |
|---|---|---|
| `block` | Започва на **нов ред**, заема цялата ширина, има `width` и `height` | `<div>`, `<p>`, `<h1>`, `<section>` |
| `inline` | Остава **в реда** с текста; `width` и `height` **не работят** | `<span>`, `<a>`, `<strong>` |
| `inline-block` | В реда като `inline`, но **има** `width` и `height` | `<button>`, `<input>` |
| `none` | Елементът **го няма**: не се вижда и не заема място | |
| `table`, `table-cell`… | Като елементите на таблица | |
| `flex`, `grid` | Отделна тема, не е част от днес | |

> 💡 **„`width` и `height` не работят"** значи, че браузърът ги **игнорира**: `inline` елементът е толкова голям, колкото е текстът в него, защото трябва да тече заедно с думите. При `block` и `inline-block` зададеният размер се спазва. Пробвайте в DevTools: сменете `width` на `<span>` и нищо няма да се промени, докато не му дадете `display: inline-block`.

**Примери:**

```css
/* Хоризонтално меню без flex: точките от списъка стават inline-block */
.menu li {
    display: inline-block;  /* в реда с текста, но с ширина и височина */
    margin-right: 1rem;  /* външно отстояние отдясно: 1rem = 16px */
}

/* Етикет („таг") в текст: в реда, но с padding и фон */
.tag {
    display: inline-block;  /* в реда с текста, но с ширина и височина */
    padding: 0.2em 0.6em;  /* вътрешно отстояние: горе/долу 0.2 × размера на шрифта, ляво/дясно 0.6 × размера на шрифта */
    background-color: #e8eef5;  /* цвят на фона */
}

/* Линкът заема цялия ред: по-голяма площ за кликване */
.big-link { display: block; padding: 1rem; }  /* блок: нов ред, цялата ширина; вътрешно отстояние 1rem = 16px от всички страни */
```

> 📌 За домашната по CSS 1 **не използвайте** `flex` и `grid`. Целта е да разберете основите, върху които те са построени.

### Как да скрием елемент?

| | Вижда се? | Заема място? | Може да се кликне? | Екранният четец го чете? |
|---|---|---|---|---|
| `display: none` | ❌ | ❌ | ❌ | ❌ |
| `visibility: hidden` | ❌ | ✅ | ❌ | ❌ |
| `opacity: 0` | ❌ | ✅ | ✅ (!) | ✅ |
| HTML атрибут `hidden` | ❌ | ❌ | ❌ | ❌ (като `display: none`) |

**Пример:** три кутии A, B, C, в които B е скрита по различен начин.

```css
.hide-display    { display: none; }      /* B го няма: C се премества на мястото му */
.hide-visibility { visibility: hidden; } /* B е невидим, но заема място между A и C */
.hide-opacity    { opacity: 0; }         /* B е прозрачен: заема място и може да се кликне */
```

> 💡 `opacity: 0` понякога се ползва **нарочно**: невидим слой върху нещо друго, който може да се кликва.

## 11. Box model

```
┌───────────────── margin ─────────────────┐
│  ┌────────────── border ──────────────┐  │
│  │  ┌─────────── padding ─────────┐   │  │
│  │  │                             │   │  │
│  │  │          content            │   │  │
│  │  │      (width × height)       │   │  │
│  │  │                             │   │  │
│  │  └─────────────────────────────┘   │  │
│  └────────────────────────────────────┘  │
└──────────────────────────────────────────┘
```

| Свойство | Какво е |
|---|---|
| `width`, `height` | Размер на **съдържанието** (по подразбиране) |
| `padding` | Разстояние между съдържанието и рамката. **Вътре** е: фонът се вижда през него. |
| `border` | Рамката: `border: 1px solid #ccc;` |
| `margin` | Разстояние **до другите** елементи. Отвън е: прозрачно. |

### `box-sizing`: капанът с ширината

```css
.box {
    width: 300px;  /* ширина: 300px */
    padding: 20px;  /* вътрешно отстояние 20px от всички страни */
    border: 5px solid black;  /* рамка: дебелина, вид, цвят */
}
```

Колко широка е кутията на екрана?

<details>
<summary>Отговор</summary>

**350px.** По подразбиране `width` е само съдържанието: 300 + 2 × 20 (padding) + 2 × 5 (border) = 350.

Със `box-sizing: border-box` кутията е точно **300px**, а съдържанието се свива, за да побере padding и border. Затова почти всеки CSS файл днес започва с:

```css
*, *::before, *::after {
    box-sizing: border-box;  /* width включва padding и border */
}
```

</details>

**Пример: двете кутии една под друга**

```css
.box-content { box-sizing: content-box; width: 300px; padding: 20px; border: 5px solid #1f4e79; } /* width е само съдържанието: 350px на екрана */
.box-border  { box-sizing: border-box;  width: 300px; padding: 20px; border: 5px solid #1f4e79; } /* width включва padding и border: точно 300px */
```

### Кратки записи (shorthand)

Вместо `margin-top`, `margin-right`, `margin-bottom`, `margin-left` може с една стойност до четири:

| Запис | Значение |
|---|---|
| `margin: 10px;` | Всички страни |
| `margin: 10px 20px;` | горе/долу · ляво/дясно |
| `margin: 10px 20px 30px;` | горе · ляво/дясно · долу |
| `margin: 10px 20px 30px 40px;` | горе · дясно · долу · ляво |

> 🧭 Четирите стойности са **по часовниковата стрелка**, започвайки отгоре: **T**op, **R**ight, **B**ottom, **L**eft = **TRBL**, като „trouble". Същото важи за `padding` и `border-width`.

**Примери:**

```css
.btn     { padding: 0.5rem 1.5rem; }     /* вътрешно отстояние: 8px отгоре/отдолу, 24px отстрани */
.card    { margin: 0 0 1rem; }           /* външно отстояние: 0 горе, 0 отстрани, 16px отдолу */
.frame   { border-width: 4px 1px; }      /* дебелина на рамката: 4px горе и долу, 1px отстрани */

/* Центриране на блок: auto разделя свободното място поравно */
.centered {
    width: 400px;  /* ширина: 400px */
    max-width: 100%;  /* максимална ширина: 100% от родителя, така на тесен екран не излиза извън страницата */
    margin: 0 auto;  /* 0 горе/долу, auto отляво/отдясно = центриране */
}
```

> ⚠️ **Сливане на margin-и:** вертикалните `margin`-и на два съседни блока **не се събират**, а се **сливат** в по-големия.
>
> ```css
> .first  { margin-bottom: 20px; }  /* външно отстояние отдолу: 20px */
> .second { margin-top: 30px; }  /* външно отстояние отгоре: 30px */
> /* разстоянието между тях е 30px, не 50px */
> ```

### Пример: всичко заедно

```html
<div class="box">Кутия</div>

<div class="content-box">content-box</div>
<div class="border-box">border-box</div>

<div class="centered">Центрирана</div>

<div class="first">Първа</div>
<div class="second">Втора</div>
```

```css
.box {
    width: 200px;                 /* ширина на съдържанието */
    padding: 20px;                /* вътрешно отстояние от всички страни */
    border: 5px solid #1f4e79;    /* рамка: 5px, плътна, синя */
    margin: 30px;                 /* външно отстояние от всички страни */
    background-color: #e8eef5;    /* фонът се вижда и през padding-а */
}

.content-box {
    box-sizing: content-box;      /* width е само съдържанието */
    width: 300px;
    padding: 20px;
    border: 5px solid #1f4e79;
}

.border-box {
    box-sizing: border-box;       /* width включва padding и border */
    width: 300px;
    padding: 20px;
    border: 5px solid #1f4e79;
}

.centered {
    width: 300px;
    margin: 20px auto;            /* 20px горе/долу, auto отляво/отдясно = центриране */
    background-color: #ffe9a8;
}

.first {
    margin-bottom: 20px;          /* 20px отдолу */
    background-color: #d4edda;
}

.second {
    margin-top: 30px;             /* 30px отгоре */
    background-color: #d4edda;
}
```

**Какво се вижда:**
- **`.box`:** изберете я с **Ctrl + Shift + C** и отворете таб **Computed**. Най-долу има цветна схема с четирите слоя: съдържание 200px, `padding` 20px, `border` 5px, `margin` 30px. Фонът се вижда през `padding`-а, но не и през `margin`-а.
- **`.content-box` срещу `.border-box`:** и двете са с `width: 300px`, но първата е **350px** на екрана (300 + 2 × 20 + 2 × 5), а втората е точно **300px**.
- **`.centered`:** `margin: 20px auto` значи 20px отгоре и отдолу, а `auto` отляво и отдясно разделя свободното място поравно. Кутията е в средата.
- **`.first` и `.second`:** между тях има **30px**, не 50px. Вертикалните `margin`-и се сливат и остава по-големият.

## 12. Position

| Стойност | Как се държи | `top` / `right` / `bottom` / `left` спрямо |
|---|---|---|
| `static` | По подразбиране. Не може да се отмества. | Не работят |
| `relative` | Остава на мястото си, но може да се **отмести** | Собствената си позиция. Мястото му остава заето. |
| `absolute` | **Излиза** от потока на страницата | Най-близкия родител с `position` ≠ `static` (иначе цялата страница) |
| `fixed` | **Залепва за екрана**, не се мести при скролиране | Прозореца (viewport) |
| `sticky` | Нормален, докато не стигне ръба при скролиране, после **залепва** | Ръба на прозореца, в рамките на родителя |

**Примери:**

```css
/* relative: леко отместване, мястото остава заето */
.nudge {
    position: relative;  /* може да се отмества; мястото му остава заето */
    top: 5px;            /* 5px надолу от нормалната позиция */
    left: 20px;          /* 20px надясно от нормалната позиция */
}

/* absolute: значка в горния десен ъгъл на картата */
.card  { position: relative; }   /* картата става „отправна точка" за .badge */
.badge {
    position: absolute;  /* излиза от потока; позиция спрямо най-близкия позициониран родител */
    top: 10px;  /* отместване от горния ръб: 10px */
    right: 10px;  /* отместване от десния ръб: 10px */
}

/* sticky: заглавието остава горе, докато скролирате неговата секция */
.sticky-title {
    position: sticky;    /* залепва при скролиране */
    top: 0;              /* залепва точно за горния ръб */
}

/* fixed: бутон „Нагоре" винаги в долния десен ъгъл на екрана */
.to-top {
    position: fixed;     /* залепен за екрана */
    bottom: 1rem;        /* 16px от долния ръб на екрана */
    right: 1rem;         /* 16px от десния ръб на екрана */
}
```

> ⚠️ При `absolute` и `fixed` родителят **не знае** за детето: детето не заема място в него и родителят може да се окаже по-малък от него.

## 13. Float + clear

`float: left / right` кара елемент да „плава" вляво или вдясно, а текстът го **обтича**. Като „Wrap text" в Word.

- Като при `absolute`, родителят **не обхваща** плаващия елемент и може да „свърши" твърде рано.
- **`clear: left / right / both`** кара елемент да започне **под** плаващите.

**Примери:**

```css
/* Снимка вдясно, текстът я обтича */
.float-photo {
    float: right;  /* плава вдясно, текстът го обтича */
    width: 150px;  /* ширина: 150px */
    margin: 0 0 1rem 1rem;  /* външно отстояние: горе 0, дясно 0, долу 1rem = 16px, ляво 1rem = 16px */
}

/* Този елемент започва под снимката */
.after-photo { clear: both; }  /* започва под всички плаващи елементи */

/* Родителят обхваща плаващите си деца (съвременно решение) */
.contains-floats { display: flow-root; }  /* обхваща плаващите си деца */

/* Старото решение (clearfix), което ще срещнете в по-стар код */
.clearfix::after {
    content: "";  /* празно съдържание: нужно е, за да съществува ::after */
    display: block;  /* блок: нов ред, цялата ширина */
    clear: both;  /* започва под всички плаващи елементи */
}
```

> 💡 Преди `flex` и `grid` целите страници се подреждаха с `float`. Днес `float` се ползва основно за **обтичане на снимка с текст**.

## 14. Други полезни свойства

| Свойство | Стойности | Какво прави |
|---|---|---|
| `z-index` | Число | Кой елемент е **отгоре**, когато се застъпват. По-голямото число е по-напред. Работи на елементи с `position` ≠ `static` (и на flex/grid деца). |
| `opacity` | `0` – `1` | Прозрачност на **целия** елемент заедно с децата му |
| `visibility` | `visible`, `hidden` | Скрива, но мястото остава заето |
| `overflow` | `visible`, `hidden`, `scroll`, `auto` | Какво става със съдържание, което не се побира. `auto` добавя скролбар **само при нужда**. |
| `vertical-align` | `top`, `middle`, `bottom`, `baseline` | Вертикално подравняване в **клетка на таблица** или на `inline-block` спрямо съседите му |
| `cursor` | `pointer`, `not-allowed`… | Видът на курсора |

**Примери:**

```css
/* z-index: две застъпващи се кутии; синята е отгоре */
.layer {
    position: absolute;  /* излиза от потока; позиция спрямо родителя */
    width: 120px;        /* ширина */
    height: 80px;        /* височина */
}
.layer.red {
    top: 0;              /* 0 отгоре */
    left: 0;             /* 0 отляво: в горния ляв ъгъл */
    z-index: 1;          /* по-долу */
}
.layer.blue {
    top: 30px;           /* 30px отгоре */
    left: 60px;          /* 60px отляво: застъпва червената */
    z-index: 2;          /* по-голямото число е отгоре */
}

/* opacity: избледнял, „неактивен" вид */
.faded { opacity: 0.5; }  /* непрозрачност 0.5: наполовина прозрачен */

/* overflow: кутия с фиксирана височина и скролбар при нужда */
.scroll-box {
    height: 100px;       /* фиксирана височина */
    overflow: auto;      /* скролбар само при нужда */
}

/* vertical-align: съдържанието на клетката е в средата */
td { vertical-align: middle; }  /* вертикално по средата */

/* cursor */
.clickable { cursor: pointer; }  /* курсор-ръка */
button:disabled { cursor: not-allowed; }  /* курсор „забранено“ */
```

> 💡 **`z-index` и родителите:** елементите се сравняват **на нива**. Ако родител А е под родител Б, детето на А с `z-index: 9999` пак ще е под Б. Затова огромните `z-index` числа рядко решават проблема.

## 15. Домашна задача: форма за регистрация

> Направете с HTML и CSS форма за регистрация, която изглежда така:
>
> - Кутия с фиксирана ширина, **центрирана** на страницата, със светъл фон и тънка сива рамка.
> - Заглавна лента със зелен фон и бял, удебелен, центриран текст „РЕГИСТРАЦИЯ".
> - Пет полета: E-mail, Име, Фамилия, Парола, Повтори паролата. Полетата заемат цялата ширина на кутията и имат еднакви отстояния между тях.
> - Бутон „Регистрация" през цялата ширина, със зелен фон и бял текст.
>
> **Изисквания:**
> - CSS-ът е във **външен файл**.
> - **Без** `flex` и `grid`.
> - Всяко поле има **правилния `type`**, **`name`** и **`<label>`**. Етикетите не трябва да се виждат на екрана: скрийте ги визуално (вижте долу), но **не** ги махайте. `placeholder` не е етикет.
> - Бутонът е истински `<button type="submit">`.
> - Бутонът и полетата имат видимо състояние при `:hover` и `:focus`.
> - Текстът „РЕГИСТРАЦИЯ" е написан нормално в HTML-а, а главните букви са с CSS.
>
> **Бонус:** изберете такъв зелен цвят, че белият текст върху него да има контраст поне **4.5 : 1** (проверете в DevTools).

### 💡 Помощ: визуално скрит етикет

Този клас скрива текста от екрана, но екранният четец пак го чете:

```css
.visually-hidden {
    position: absolute;  /* излиза от потока; позиция спрямо най-близкия позициониран родител */
    width: 1px;  /* ширина: 1px */
    height: 1px;  /* височина: 1px */
    margin: -1px;  /* външно отстояние -1px от всички страни */
    padding: 0;  /* без вътрешно отстояние */
    overflow: hidden;  /* скрива всичко, което не се побира */
    clip: rect(0, 0, 0, 0);  /* изрязва видимата част до нищо */
    white-space: nowrap;  /* текстът не се пренася на нов ред */
    border: 0;  /* без рамка */
}
```

```html
<label for="email" class="visually-hidden">E-mail</label>
<input id="email" name="email" type="email" placeholder="E-mail">
```

> Използва само неща от днес: `position`, `width`, `height`, `margin`, `padding`, `overflow`, `border`.
